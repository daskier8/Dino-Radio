DinoRadio

One-time setup (about 5 minutes)

Dino Radio plays songs from Spotify and finds similar music using Last.fm. Each service needs a free key that only you use. You need Spotify Premium.

You opened this file directly from your computer. Spotify sign-in needs it opened from a web address: use your hosted link, or double-click Start Dino Radio.bat.
  1. Create a Spotify app
    Open developer.spotify.com/dashboard, sign in with your Premium account, and click Create app. Use any name and description. Add this as a Redirect URI (if your app already exists, open it, go to Settings → Edit, and add it as an extra one):
    Under “Which API/SDKs”, tick Web API and Web Playback SDK, then save. Copy the Client ID from the app's page (you don't need the Client Secret).
  2. Get a free Last.fm API key
    Open last.fm/api/account/create (sign up if needed). Any app name works, and you can leave the callback blank. Copy the API key.
  3. Paste both keys here

The keys are saved only in this browser. On another device (like your phone), you paste them once more.

    Set up your DJ Room

    The room uses Google Firebase (free) so everyone sees the same song, waitlist and chat in real time. It takes about 10 minutes, once. Your friends won't need to do this; they just open your invite link.

    1. Create a Firebase project
      Go to console.firebase.google.com → Create a project, name it dino-radio, and turn Google Analytics off.
    2. Turn on anonymous sign-in
      Left menu → Build → Authentication → Get started → Sign-in method tab → Anonymous → Enable → Save.
    3. Create the database
      Build → Realtime Database → Create Database → pick the United States location → Start in locked mode → Enable. Then open its Rules tab, replace everything with this, and click Publish: 
      {
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
    4. Register the web app
      Click the ⚙️ next to Project Overview → Project settings → under “Your apps” click the </> (Web) icon → nickname dino → Register app. Copy the whole firebaseConfig = { … } block it shows and paste it below.
    5. Paste and create

            Sync between devices

            Keeps your stations, thumbs and what each station has learned the same on your PC and phone. Everything is stored in a private file in your own GitHub account.

            1. Make a GitHub token (one time)
              Open this GitHub page. The name and the gist permission are already filled in. Set Expiration to No expiration, click Generate token at the bottom, and copy the token (it starts with ghp_).
            2. Paste it here
            3. On your other device
              Open Dino Radio → Sync devices, then paste the same token. Stations from both devices are combined.
            No GitHub? Copy and paste instead

            One-time copy: copy on one device, send it to yourself, and paste it on the other.
