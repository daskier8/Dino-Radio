DriftRadio

One-time setup (about 5 minutes)

Drift Radio plays songs from Spotify and finds similar music using Last.fm. Each service needs a free key that only you use. You need Spotify Premium.

You opened this file directly. Close this tab and double-click Start Drift Radio.bat instead. Spotify sign-in only works at http://127.0.0.1:8888/.
  1. Create a Spotify app
    Open developer.spotify.com/dashboard, sign in with your Premium account, and click Create app. Use any name and description. Paste this as the Redirect URI:
    Under “Which API/SDKs”, tick Web API and Web Playback SDK, then save. Copy the Client ID from the app's page (you don't need the Client Secret).
  2. Get a free Last.fm API key
    Open last.fm/api/account/create (sign up if needed). Any app name works, and you can leave the callback blank. Copy the API key.
  3. Paste both keys here

The keys are saved only in this browser on this computer.
